# Demo Script

## 2-Minute Prototype Walkthrough

1. Open PathWise AI and introduce the problem: students know the role they want, but not the exact path.
2. Click `Demo / Sign in`, then `Enter demo mode`.
3. Show the dashboard sections: goal summary, next best action, missing skills, weekly roadmap, projects, interview prep, and progress tracker.
4. Point out the readiness score and explain that it improves as weeks are completed.
5. Toggle one weekly checkbox to show the progress bar and readiness score change.
6. Open `Roadmap` and highlight week-by-week outcomes, tasks, resources, and estimated hours.
7. Open `Prep kit` and show 3 portfolio projects plus 5 interview questions.
8. Return to onboarding and generate a new plan for a role like `Data Analyst`.
9. Mention that Gemini powers the structured guidance, while Supabase persists authenticated user data.

## Judge Talking Points

- Works without setup through demo mode.
- Uses strict JSON prompts and typed validation for reliable AI output.
- Stores real progress in Supabase when env vars are configured.
- Scope is intentionally tight for a polished MVP.

## Backup Plan

If Gemini or Supabase is unavailable, use demo mode. The app still shows the complete end-to-end user flow with realistic sample data.
